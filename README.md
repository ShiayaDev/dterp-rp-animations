# DTERP RP Animations

![FiveM](https://img.shields.io/badge/FiveM-Script-orange)
![Lua](https://img.shields.io/badge/Language-Lua-blue)
![Version](https://img.shields.io/badge/Version-1.0.0-green)
![License](https://img.shields.io/badge/License-MIT-yellow)

A high-quality FiveM script that adds fully synced roleplay animations including pointing and hands up, with support for ESX, QB-Core, Qbox, and standalone servers.
<img width="899" height="26" alt="image" src="https://github.com/user-attachments/assets/e567fe32-d845-42b2-a195-aa9db8c0111b" />

## Features

✔ Fully synced pointing system (NoPixel-style)  
✔ Fully synced hands up animation  
✔ Smooth camera-based pointing  
✔ Player-changeable keybinds (FiveM settings)  
✔ Framework compatible (ESX, QB-Core, Qbox, standalone)  
✔ Automatic state syncing using StateBags  
✔ Optimized loops (low CPU usage)  
✔ Built-in restrictions (dead, aiming, vehicles, cuffed)  
✔ Clean and modular code structure  

## Keybinds

| Action   | Default Key |
|----------|------------|
| Point    | B          |
| Hands Up | X          |

## Restrictions

Animations are automatically disabled when:

- Player is dead  
- Player is aiming  
- Player is in a vehicle (hands up)  
- Player is cuffed/restrained  

## Installation

1. Download or clone this repository
2. Place it in your `resources` folder
3. Add to your `server.cfg`:
4. ensure dterp-rp-animations
5. Restart your server

## Configuration

No configuration required.

Keybinds can be changed in-game via FiveM settings.

## Customization

Developers can easily modify:

- Keybinds  
- Animation behavior  
- Cuff detection logic  
- Framework integrations  

## Requirements

None (Standalone)
